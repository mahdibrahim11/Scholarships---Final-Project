Scholarship System ERD

Entity-relationship design for the scholarship import, search, match, and admin features.

Assumption

This ERD is based on the required screens: Home, Import, Import Validation Report, Admin Scholarship List, Scholarship Edit, Search Results, Scholarship Detail, My Matches, Login/Register, and User Management.

Entities

User

  • PK user_id
  • first_name
  • last_name
  • email
  • password_hash
  • role
  • status
  • created_at

UserProfile

  • PK profile_id
  • FK user_id
  • major
  • gpa
  • academic_level
  • state
  • financial_need
  • citizenship_status

Scholarship

  • PK scholarship_id
  • title
  • provider
  • amount_min
  • amount_max
  • deadline
  • description
  • apply_url
  • status
  • FK import_batch_id

EligibilityTag

  • PK tag_id
  • tag_name
  • category

ScholarshipTag

  • PK/FK scholarship_id
  • PK/FK tag_id

UserProfileTag

  • PK/FK profile_id
  • PK/FK tag_id

MatchResult

  • PK match_id
  • FK user_id
  • FK scholarship_id
  • match_score
  • match_reason
  • created_at

SavedScholarship

  • PK/FK user_id
  • PK/FK scholarship_id
  • saved_at

Application

  • PK application_id
  • FK user_id
  • FK scholarship_id
  • status
  • notes
  • applied_at

ImportBatch

  • PK import_batch_id
  • FK uploaded_by_user_id
  • file_name
  • status
  • rows_total
  • rows_valid
  • rows_invalid
  • created_at

ImportError

  • PK error_id
  • FK import_batch_id
  • row_number
  • field_name
  • error_message

AuditLog

  • PK audit_id
  • FK user_id
  • action
  • entity_type
  • entity_id
  • created_at

Relationships

User 1 — 1 UserProfile
User 1 — many MatchResult; Scholarship 1 — many MatchResult
User many — many Scholarship through SavedScholarship
User many — many Scholarship through Application
Scholarship many — many EligibilityTag through ScholarshipTag
UserProfile many — many EligibilityTag through UserProfileTag
User 1 — many ImportBatch; ImportBatch 1 — many ImportError
ImportBatch 1 — many Scholarship
User 1 — many AuditLog
