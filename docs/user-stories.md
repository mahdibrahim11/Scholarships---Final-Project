# User Stories

## Visitor
-As A visitor, I want to look through available scholarships, with that I can see what opportunities are out there
-As a visitor, I want to look through scholarships, read the details so I can Assess if I'm Qualified
-As a Visitor, I want to register an Account, so I can use the website's features

## Parent
-As a Parent, I want to create profiles for the children to keep Scholarship Info Organized
-As a parent i Want to view scholarship matches for each child so I can help them find opportunities
-As a Parent, I want to see saved scholarships for each child, So I can track what their Interests are
-As a parent I want to track scholarship deadlines for each child so We don't miss any
-As a parent I want to update each child's grade, state and interests so their matches stay Accurate

## Student
-As a Student, I want to view my profile, update the profile, so that I'm Able to know my grade, what state I'm from and my Interests
-I want to also see Scholarships that match my updated profile, so I can find opportunities that fit me.
-I want to save my scholarships so I can come back to them Later
-As a Student, I want to track application Status, So I know which Scholarships I am working on
-As A student, I want to see upcoming scholarship deadlines, So I don't miss an application date

## Admin
-As an Admin, I want to add new scholarships so the website is up to date
-As an admin, i want to Edit scholarship information so I can correct mistakes
-As An Admin, I want to verify scholarships so users know the info has been checked and verified
-As an admin, I want to review imported scholarship data so I can find errors before anyone else finds them
-As An Admin, I want to manage scholarship providers so Organization information stays Accurate.

## Super-Admin
-As a super admin, I want to create and manage user accounts so I can control who has access to the system
-As a super admin, I want to change user roles, or delete accounts so permissions stay up to date
-As a super admin, I want to view the audit log so I can see important actions that happened in the system
